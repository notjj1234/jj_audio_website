# UI/UX issues

Visual and interaction register for desktop Streamlit (`ui/`) and the hosted React SPA (`web/`). This file does **not** replace `docs/issues.md` (engine, isolation policy, reserved historical IDs). New IDs start at **I-600**. File surface bugs only; do not treat model quality, RAM, MPS, or duration gates as UI defects unless a control or caption is wrong.

**Kind key**

| Kind | Meaning |
|------|---------|
| documented tradeoff | Known UI limit (Streamlit chrome, product split). Not a forgotten bug. |
| unfixed gap | We could align copy, layout, or chrome; it is not done. |
| implemented-in-code | Gap closed in code; remaining text is history. |
| unknown | Not verified here. |

Do **not** reuse I-072, I-098, I-104, I-200–I-252, or I-500–I-509.

Desktop **Interface Lite** (sidebar radio) is not hosted processing mode `lite`. Streamlit’s file watcher being off is a tester restart, not a product bug.
