## Phase 1 — Critical (I-200, I-201, I-202)

Three issues that block shipping. Estimated effort: small.

### I-200: Infinite rerun loop when picked library run is deleted

**File:** `ui/pages/isolate.py` ~line 2233

**Root cause:** `_apply_listen_pick` sets `LISTEN_PICKER_NEXT_KEY = loaded_dir` then `st.rerun()`. If the dir is gone, the rerun re-applies the dead dir → loop.

**Fix:**
1. In `_apply_listen_pick` (or wherever `LISTEN_PICKER_NEXT_KEY` is set), check `loaded_dir.is_dir()` before setting it.
2. If the dir doesn't exist, clear `LISTEN_PICKER_KEY` to empty and set `isolate_listen_missing = True` (one-time message), then `st.rerun()` — no loop.

### I-202: Frozen app can't find bundled ffmpeg

**File:** `ui/desktop_export.py` ~line 86

**Root cause:** `_ffmpeg_path()` only calls `shutil.which("ffmpeg")`. Frozen builds bundle ffmpeg under `packaging/ffmpeg/` but that path isn't on PATH.

**Fix:**
1. In `_ffmpeg_path()`, after `shutil.which("ffmpeg")` returns `None`, check `getattr(sys, "_MEIPASS", None)` and look for `ffmpeg` in the PyInstaller bundle directory.
2. Also check a sibling path relative to `__file__` (for dev mode): `Path(__file__).resolve().parents[2] / "packaging" / "ffmpeg" / "ffmpeg"` (or platform-appropriate name).
3. Log a warning when falling back to the bundle path.

### I-201: ffmpeg export runs with no spinner (UI freezes)

**File:** `ui/pages/isolate.py` ~lines 1807–1822

**Root cause:** `desktop_export.convert_audio` runs synchronously inside the render path with no `st.spinner()`.

**Fix:**
1. Wrap the `_save_all_tracks` / `_save_current_mix` calls in `with st.spinner(f"Converting to {fmt}..."):`.
2. Keep the `st.success()` at the end.
